Pluralsight MCP Cookbook

Copy-ready prompts for the Pluralsight MCP Server. Search the library, find tutorial clips, check your activity, and build learning plans from your AI assistant.

View the repo on GitHub

Quick start (Claude Code)

/plugin marketplace add pluralsight/pluralsight-mcp-cookbook
/plugin install pluralsight@pluralsight

Authenticate with your Pluralsight account on first use. Other setups: installation guide.

Prompts come from the examples/ folder of the repo. MIT licensed.
