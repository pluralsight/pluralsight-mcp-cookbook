# Send Feedback to Pluralsight

**Goal:** Tell the Pluralsight team what's working, what's missing, and what broke — directly from your assistant.

## Prompt

```text
I want to send feedback about the Pluralsight MCP server.
```

## Tools used

- `submit_user_feedback` — the assistant will walk you through five short questions, one at a time:
  1. Any technical issues connecting to or using the server
  2. Scenarios where the tools were useful (and which platform you used)
  3. Tools you reached for that weren't available
  4. Tools that didn't deliver what you expected
  5. Anything else

## What to expect

A short guided conversation, then a confirmation that your feedback was submitted. You can decline any question — the assistant will record "no response" for it. This feedback goes to the team building the MCP server, so it's the best channel for feature requests.
