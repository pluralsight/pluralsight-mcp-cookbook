# Examples

Copy-paste prompts and workflows for the Pluralsight MCP Server, organized from simple to complex. Each example states its goal, the prompt to use, which MCP tools it exercises, and what to expect.

**Prerequisite:** the Pluralsight MCP server connected to your client — either via the [plugin](../plugins/pluralsight/README.md) or [manual setup](../docs/installation.md#manual-mcp-setup-without-the-plugin).

## Levels

### [01 — Getting started](01-getting-started/README.md)

Single prompts that exercise one MCP tool each. Start here to verify your connection and learn what each tool does.

### [02 — Intermediate](02-intermediate/README.md)

Prompts that combine multiple tools in one request — personalized recommendations, progressive course sequences, and targeted content deep-dives.

### [03 — Advanced](03-advanced/README.md)

Skill- and agent-driven workflows: reusable skills, the learning-advisor agent, and multi-step patterns you can adapt for teams.

## Example format

Every example follows the same template (see [docs/adding-examples.md](../docs/adding-examples.md) to contribute your own):

- **Goal** — what you accomplish
- **Prompt** — copy-paste text
- **Tools used** — which MCP tools the assistant should call
- **What to expect** — the shape of a good response
